# Customer Churn Prediction Using Machine Learning

## Project Overview
This project predicts whether a telecom customer is likely to leave a company's services using machine learning.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib

## Machine Learning Algorithms
- Logistic Regression
- Random Forest Classifier

## Project Workflow
1. Data collection
2. Exploratory Data Analysis
3. Data cleaning
4. Data visualization
5. Feature engineering
6. Model training
7. Model evaluation and comparison
8. Customer churn prediction

## Model Results

| Model | Accuracy |
|---|---:|
| Logistic Regression | 80.70% |
| Random Forest | 77.43% |

## How to Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the prediction system:

```bash
python src/predict_customer.py
```

## Project Objective
To identify customers who may leave a telecom service and help businesses improve customer retention.
